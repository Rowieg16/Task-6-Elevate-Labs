##  Analysis

## Weak Passwords
- `password123`, `Password123`, `P@ssw0rd!`
- Common patterns and predictable substitutions
- Vulnerable to dictionary attacks

## Strong Passwords
- `X7#kL9!qZ2`, `MyDog@2024!`, `$Tr0ngP@ssW0rd#2026`
- High randomness and longer length
- Use of mixed characters improves strength



##  Key Learnings

- Symbols alone do **not** guarantee strong passwords  
- **Length + randomness** is more important than complexity alone  
- Predictable substitutions (`@`, `0`, etc.) are easily guessed  
- Passphrases are both **secure and easier to remember**



##  Best Practices for Strong Passwords

- Use **12–16+ characters**
- Include:
  - Uppercase letters (A–Z)
  - Lowercase letters (a–z)
  - Numbers (0–9)
  - Symbols (!@#$%^&*)
- Avoid:
  - Common words (`password`, `admin`)
  - Personal information
- Use **unique passwords** for each account
- Enable **Two-Factor Authentication (2FA)**



##  Common Password Attacks

## Brute Force Attack
- Attempts every possible combination  
- Time increases with password complexity  

##  Dictionary Attack
- Uses a list of common passwords  
- Quickly cracks weak passwords  

##  Credential Stuffing
- Uses leaked credentials from other sites  
- Effective if passwords are reused  



## Conclusion

- Weak passwords can be cracked **very quickly**
- Strong passwords significantly improve security
- The best approach is using **long, random, and unique passwords**
